Landnod QGIS plugins

Independent tools for QGIS 4, with English plugin names and a Slovak interface.

Add a plugin repository named Landnod in QGIS with this URL:

https://landnod-dev.github.io/landnod-qgis-plugin-repository/plugins.xml

  • Landnod Share Layer Styles

  • Landnod Pricing and Planning

QGIS repository XML · Release downloads

Configure your database credentials through QGIS Authentication Manager. Packages contain no database credentials or project data.
